

# Lost and Found App 🔍

## About the Project
Lost and Found is a simple mobile application developed using SwiftUI.

It helps users view lost and found items and search for belongings.

## Features
- View lost items
- View found items
- Search items by name
- View item details
- Navigate between screens
- Display item location and status

## Technologies Used
- Swift
- SwiftUI
- NavigationStack
- VStack and HStack
- List
- State Management
